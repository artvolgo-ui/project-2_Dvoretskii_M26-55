# Primitive DB

**Primitive DB** — это консольное приложение на Python, которое имитирует работу с базой данных. Программа позволяет создавать таблицы с заданной структурой столбцов, просматривать список существующих таблиц и удалять их. Все метаданные (структура таблиц) автоматически сохраняются в локальный JSON-файл, обеспечивая персистентность данных между запусками.

## Установка

Для установки пакета в качестве изолированного CLI-инструмента используйте пакетный менеджер `uv`:

```bash
uv tool install primitive_db
```

## Запуск

После установки база данных запускается простой командой в терминале:

```bash
database
```
## Управление таблицами

После запуска программы вам будет доступен интерактивный режим. Ниже приведен список поддерживаемых команд:

| Команда | Описание |
| :--- | :--- |
| `create_table <имя> <столбец1:тип> ...` | Создать новую таблицу. Автоматически добавляет уникальный ключ `ID:int`. Поддерживаемые типы: `int`, `str`, `bool`. |
| `list_tables` | Показать список всех существующих таблиц. |
| `drop_table <имя>` | Удалить указанную таблицу. |
| `help` | Показать справочную информацию по командам. |
| `exit` | Выйти из программы. |

### Пример использования

```text
***База данных***
Функции:
<command> create_table <имя_таблицы> <столбец1:тип> .. - создать таблицу
<command> list_tables - показать список всех таблиц
<command> drop_table <имя_таблицы> - удалить таблицу

Общие команды:
<command> exit - выход из программы
<command> help - справочная информация

>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>>Введите команду: create_table users name:str
Ошибка: Таблица "users" уже существует.

>>>Введите команду: list_tables
- users

>>>Введите команду: drop_table users
Таблица "users" успешно удалена.

>>>Введите команду: exit
Выход из программы.
```
