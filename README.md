# Primitive DB

**Primitive DB** — это консольное приложение на Python, которое имитирует работу с базой данных. Программа позволяет создавать таблицы с заданной структурой столбцов, просматривать список существующих таблиц и удалять их. Все метаданные (структура таблиц) автоматически сохраняются в локальный JSON-файл, обеспечивая персистентность данных между запусками.

## Установка

Для установки пакета в качестве изолированного CLI-инструмента используйте пакетный менеджер `uv`:

```bash
uv tool install primitive_db
```

## Запуск

После установки база данных запускается простой командой в терминале:

```bash
database
```
## Управление таблицами

После запуска программы вам будет доступен интерактивный режим. Ниже приведен список поддерживаемых команд:

| Команда | Описание |
| :--- | :--- |
| `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` | Добавить новую запись. Значения должны строго соответствовать типам столбцов. `ID` генерируется автоматически. |
| `select from <имя_таблицы>` | Показать все записи в таблице. |
| `select from <имя_таблицы> where <столбец> = <значение>` | Показать записи, соответствующие условию. |
| `update <имя_таблицы> set <столбец> = <новое_значение> where <столбец_условия> = <значение_условия>` | Обновить значения в записях, подходящих под условие. |
| `delete from <имя_таблицы> where <столбец> = <значение>` | Удалить записи, подходящие под условие. |
| `info <имя_таблицы>` | Показать информацию о таблице (названия столбцов и количество записей). |
