# Primitive DB

**Primitive DB** — это консольное приложение на Python, которое имитирует работу с базой данных. Программа позволяет создавать таблицы с заданной структурой столбцов, просматривать список существующих таблиц и удалять их. Все метаданные (структура таблиц) автоматически сохраняются в локальный JSON-файл, обеспечивая персистентность данных между запусками.

## Установка

Для установки пакета в качестве изолированного CLI-инструмента используйте пакетный менеджер `uv`:

```bash
uv tool install primitive_db
```

## Запуск

После установки база данных запускается простой командой в терминале:

```bash
database
```
## Управление таблицами

После запуска программы вам будет доступен интерактивный режим. Ниже приведен список поддерживаемых команд:

| Команда | Описание |
| :--- | :--- |
| `create_table <имя> <столбец1:тип> ...` | Создать новую таблицу. Автоматически добавляет уникальный ключ `ID:int`. Поддерживаемые типы: `int`, `str`, `bool`. |
| `list_tables` | Показать список всех существующих таблиц. |
| `drop_table <имя>` | Удалить указанную таблицу. |
| `help` | Показать справочную информацию по командам. |
| `exit` | Выйти из программы. |


## CRUD-операции

После того как таблица создана, с ней можно работать, добавляя, изменяя и удаляя записи. 
Все изменения автоматически сохраняются в JSON-файлы в папке `data/`.

| Команда | Описание |
| :--- | :--- |
| `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` | Добавить новую запись. `ID` генерируется автоматически. |
| `select from <имя_таблицы>` | Показать все записи в таблице. |
| `select from <имя_таблицы> where <столбец> = <значение>` | Показать записи, соответствующие условию. |
| `update <имя_таблицы> set <столбец> = <новое_значение> where <столбец_условия> = <значение_условия>` | Обновить значения в записях, подходящих под условие. |
| `delete from <имя_таблицы> where <столбец> = <значение>` | Удалить записи, подходящие под условие (требует подтверждения). |
| `info <имя_таблицы>` | Показать информацию о таблице. |

### Пример использования

```text
>>> Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".
Функция insert выполнилась за 0.001 секунд.

>>> Введите команду: select from users where age = 28
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei | 28  |    True   |
+----+--------+-----+-----------+

>>> Введите команду: delete from users where ID = 1
Вы уверены, что хотите выполнить "удаление записей"? [y/n]: y
Запись с ID=1 успешно удалена из таблицы.
```

## Обработка ошибок и безопасность

Приложение использует продвинутые возможности Python (декораторы) для повышения надежности и удобства работы:

*   **Обработка ошибок (`handle_db_errors`)**: Все критические ошибки (например, неверный тип данных, попытка создать существующую таблицу или удалить несуществующую) перехватываются автоматически. Программа не завершится с ошибкой (трейсбеком), а выведет понятное сообщение.
*   **Подтверждение опасных действий (`confirm_action`)**: Перед удалением таблицы или записей программа запросит подтверждение. Вам нужно будет ввести `y` (да) или `n` (нет). Это защищает от случайной потери данных.
*   **Кэширование и замер времени**: Результаты запросов `select` кэшируются для ускорения повторных запросов. А выполнение операций добавления (`insert`) замеряется по времени и выводится в консоль.
